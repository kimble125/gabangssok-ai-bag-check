# 챙겼지 — 가정통신문 준비물 헬퍼 (PoC)

가정통신문 → AI 추출 → 앱 캘린더(MCP) 등록 → 날씨·미세먼지 기반 준비물 추가 → 전날·당일 알림.
모바일 웹으로 보는 앱입니다.

## 실행

```bash
cp .env.example .env   # ANTHROPIC_API_KEY 입력
docker compose up -d --build
# http://<서버>:6110
```

## 흐름

| 단계 | 구현 | 파일 |
|---|---|---|
| 1. 통신문 가져오기 | 링크(교육청 학교 홈페이지 게시판 `th.title`/`tr.cont` 파싱, HWP 첨부 링크 추출) · 붙여넣기 · 사진 | `app/notice.py` |
| 2. 정보 추출 | Claude 구조화 출력: 행사일·회신 마감을 별도 일정으로, 원문 준비물 / AI 추천 준비물 구분 | `app/extract.py` |
| 3. 확인·수정 | 미리보기에서 날짜·시간·장소·준비물 편집 후 "캘린더에 넣기" | `app/static/app.js` |
| 4. 캘린더 등록 (MCP) | 앱 캘린더를 MCP 서버(`/mcp/`)로 노출, 웹 앱이 MCP 클라이언트로 `add_event` 호출 | `app/calendar_mcp.py`, `main.py` `/api/notice/commit` |
| 5. 날씨 준비물 | 강수 → 우산/접이식 우산/우비, 미세먼지 나쁨 → KF80, 매우나쁨 → KF94, 추위·더위 보조 | `app/weather.py` |
| 6. 알림 | 전날 19:00 가방 싸기, 당일 07:30(마감은 08:30) 최종 확인. 발송 시점의 체크 상태·날씨로 메시지 생성 | `app/reminders.py` |

### 날씨 규칙

- 강수확률(활동 시간대 최대) ≥ 60% 또는 하루 강수 ≥ 1mm → **우산** (+ 야외면 우비·여벌 양말)
- 30~59% → **접이식 우산**
- PM10 > 80 또는 PM2.5 > 35 (나쁨) → **KF80 마스크**, 매우나쁨(PM10 > 150 / PM2.5 > 75) → **KF94 마스크**
- 예보: Open-Meteo(16일) → 실패 시 MET Norway(약 9일, 확률 없음 → 강수량·날씨기호로 판단). 미세먼지: Open-Meteo Air Quality(5일). 모두 API 키 불필요.
- 예보 범위 밖 일정은 10분마다 도는 백그라운드 작업이 범위에 들어오면 자동으로 채웁니다(3시간 캐시).
- 상세 화면의 **시연: 비 온다면? / 미세먼지 나쁨** 버튼은 발표용 가정 날씨입니다.

## 우리 미션 (`/kid?e=<일정id>`)

부모 화면의 일정 상세·홈 카드에서 **🧒 아이랑 가방 싸기**로 들어갑니다.

1. **펼치기** — 큰 그림 카드 2열. 카드를 누르면 이름을 읽어 줌(🔈 전체 읽기). 날씨 준비물은 "비 소식이 있대요"처럼 아이 말로.
2. **다 펼쳤어! 📷** — 펼친 준비물 사진을 찍으면 Claude 가 사진에 보이는 것을 체크하고, 안 보인 것만 다음 단계로.
   사진 없이 하나씩도 가능.
3. **하나씩** — 한 화면에 카드 하나, 진행 점, "넣었어!"(가방으로 들어가는 애니메이션) / "아직 못 찾았어".
4. **결과** — 넣었음·아직 카드, 카드를 다시 누르면 다시 빼기. 다 넣었을 때만 축하(코인·연속 기록 같은 보상 없음).
5. **엄마에게 보여 주기** — 부모 화면 알림(🔔)으로 결과 전송.

## MCP 서버

`http://<서버>:6110/mcp/` (Streamable HTTP, stateless)
도구: `add_event`, `list_events`, `get_checklist`, `check_item`, `delete_event`

```bash
claude mcp add --transport http school-calendar http://localhost:6110/mcp/
# → "모레 준비물 뭐야?" 를 Claude 에게 물으면 get_checklist 로 답함
```

## 남은 일

- 브라우저 알림은 HTTPS 에서만 동작 (지금은 앱 안 토스트·🔔 표시). 실제 푸시는 HTTPS + Web Push(VAPID) 필요
- HWP 첨부 본문 파싱 (지금은 게시글 본문만 사용 — 교육청 게시판은 본문에 통신문 전문이 들어 있음)
- 기상청 단기예보·에어코리아 API 로 교체 (공공데이터포털 키 필요, 국내 정확도↑)
- 로그인·가족 공유, 자녀별 학년·반 필터
