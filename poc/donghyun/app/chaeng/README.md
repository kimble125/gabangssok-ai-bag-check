# 가방쏙(옛 이름 챙겼지) 추가 기능 (호연 몫, 2026-11-19–20)

동현님의 본체(`poc/donghyun/app`) 위에 얹은 부분이다. 본체의 화면·저장소·알림을 그대로 쓰고 새 주소는 `/api/plus/…` 아래에 둔다.

## 무엇을 더했나

| 기능 | 하는 일 | 파일 |
|---|---|---|
| 추천 | 일정 제목으로 상황(현장체험학습, 생존수영 …)을 찾아 통신문에 없는 준비물을 '추천'으로 따로 보여 준다. 날씨·활동(비, 미세먼지, 더위, 추위, 젖는 활동, 버스), 아이 특성(멀미, 안경 …), 집에서 정한 꼬리표(항상 챙기는 것). 받아들인 것만 준비물 수에 들어간다. 통신문이 가져오지 말라고 한 것은 추천하지 않는다 | `recommend.py`, `scenarios.json` |
| 금지·조건 표시 | 통신문 글에서 "가져오지 않습니다 / 불가 / X", 괄호 속 조건("플라스틱 물통"), "등"으로 끝나는 목록, "필요한 학생", "우천 시"를 규칙으로 뽑아 카드·읽어 주기·결과·보호자 화면에 끝까지 남긴다. 원문 전체는 저장하지 않고 항목이 나온 줄만 근거로 둔다 | `guard.py` |
| 아이 미션 보강 | '이것도 챙길까?'(추천 하나씩), 사진에 금지물이 보이면 '이건 두고 가자', 조건을 읽어 주기, 추천 표시, 저장이 된 뒤에만 체크 반영, 스티커판 | `../static/kid.*` |
| 칭찬 스티커 | 보호자가 일정 상세에서 스티커와 한마디를 주면 아이 스티커판에 붙는다 | `service.py`, `../static/plus.js` |
| 돌아오기 | 집에 와서 가져간 것을 다시 확인한다(먹고 쓰고 없어지는 것은 뺀다). `/kid?e=<id>&mode=home` | `service.py`, `../static/kid.js` |
| 말투 틀 | 달력·알림 글을 보통 / 귀엽게 / 또박또박으로. 숫자와 목록은 코드가 채운다 | `tone.py` |
| 평소 일정 | 통신문 없이 상황만 골라 일정을 만든다(기본 준비물이 추천으로 들어간다) | `service.quick_event` |
| 예시 모드 | 모델을 부르지 않고 규칙으로 통신문을 읽는다. API 키가 없어도 흐름이 돈다 | `simple_extract.py`, `../../demo_server.py` |
| 화면 구조도 | 넓힌 그림의 찾기(수납)·돌아오기(귀가) 화면 순서 설계안. `/static/design/uiux.html` | `../static/design/uiux.html` |
| 서버 없이 도는 판 | 같은 화면과 같은 계산 코드를 브라우저 안(Pyodide)에서 돌린다. `python3 build_site.py` → 저장소의 `docs/demo`. 화면의 `/api/` 요청을 `demo_server.dispatch()`로 보낸다 | `../../build_site.py`, `../../web_demo/` |
| 이번엔 빼기 | 통신문에는 있지만 이번엔 안 가져가는 것(예: 학교에 이미 있음)을 보호자가 표시한다. 지우지 않고, 세지 않고, 아이 화면에는 회색 한 줄로 알린다. 금지(통신문이 가져오지 말라고 한 것)와는 다른 것이다 | `service.set_skipped`, `../static/plus.js`, `../static/kid.js` |

## 데이터의 근거

`scenarios.json`의 학교 행사 8개는 실제 초등학교 가정통신문 23건(학교 홈페이지 게시판, 2026-11-19 확인)에서 본 준비물이다. 항목의 `seen_in`이 `sources`의 번호다. 평소 일정 6개와 `[제안]` 표시는 근거 통신문이 없는 제안이다. 화면에는 "비슷한 알림장 n건에서 봤어요" 또는 "가방쏙 제안"으로 나온다. 약은 추천으로 아이 화면에 나오지 않고 보호자 화면에 '보호자가 정해요'로만 나온다.

## 돌려 보기

```bash
cd poc/donghyun
python3 -m unittest discover -s tests -v      # 시험 62개(모델·네트워크 없음)
python3 demo_server.py                        # http://127.0.0.1:6111 (파이썬 3.10 이상, 설치 없음)
```

예시 서버는 지어낸 예시 일정 두 개로 시작한다. 아이 화면의 '예시 사진으로 해 보기' 세 버튼(다 있음 / 몇 개 안 보임 / 유리병이 있음)은 사진을 실제로 보지 않고 준비된 결과를 돌려준다(화면에 예시라고 적혀 있다).

## 본체(FastAPI)에 붙는 자리

- `app/main.py`: `plus_router`를 붙이는 세 줄(실패해도 본체는 뜬다)
- `app/db.py` `replace_weather`: 날씨 준비물을 다시 계산해도 항목 번호가 바뀌지 않게 고침
- `app/reminders.py`: 돌아오기 보고(`home`)도 미리 만든 글을 그대로 보냄
- `app/static/index.html`: `plus.js` 한 줄. `app.js`는 두 군데(값 이스케이프, 링크 주소 확인)만 고침
- `app/static/kid.html|js|css`: 아이 화면을 고쳐 썼다(원래 흐름과 모양은 그대로)

## 정한 규칙 (시험으로 묶어 둔 것)

- 통신문에 적힌 것과 추천을 섞지 않는다. 받아들인 추천만 준비물 수에 들어가고, 날씨·AI가 자동으로 붙인 것은 안 넣어도 끝을 막지 않는다
- 금지 목록은 알려 주기만 한다. 사진에 보였다고 표시된 것만 아이가 '뺐어'를 누를 때까지 "다 챙겼지"를 막는다
- 통신문이 가져오지 말라고 한 것은 추천하지 않고, 자동으로 붙은 항목이 금지와 겹치면 아이 화면에서 뺀다
- 약과 "필요한 학생만" 준비물은 받아들여도 아이 화면에 나오지 않는다(보호자 화면에만)
- "우천 시" 준비물은 비 소식이 있을 때만 센다. '선택'이라고 적힌 것만 선택이다
- 같은 물건 판정은 낱말이 같거나 같은 뜻 묶음일 때만(안경과 안경집은 다른 물건)
- 일정을 지우면 딸린 근거 줄·스티커·상태도 지운다

2026-11-19 밤 GPT 독립 검토(필수 13·선택 8)를 반영했다. 남긴 것: 요청 본문 크기를 받는 중에 끊는 일(FastAPI 쪽 설정), 여러 요청이 같은 일정 상태를 동시에 고칠 때의 덮어쓰기, 화면 동작의 자동 시험.

## 아직 확인하지 못한 것

- **FastAPI 본체에서의 실행**: 이 부분을 만든 환경에는 FastAPI·Anthropic 패키지가 없어 `router.py`와 `vision.py`는 문법 확인만 했다. Docker로 띄워 `/api/plus/mode`가 열리는지, 실제 사진으로 `/api/plus/events/<id>/photo-check`가 도는지 확인이 필요하다.
- **실제 사진 시험**: 사진 확인(금지물 찾기 포함)의 정확도는 재지 않았다. 예시 서버의 결과는 준비된 것이다.
- 통신문 규칙(`guard.py`)은 예시 통신문 3개와 실제 통신문 문장 몇 개로만 시험했다. 표현이 다르면 놓칠 수 있어 화면에 근거 줄을 같이 보여 준다.
