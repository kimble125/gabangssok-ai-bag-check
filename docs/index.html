왜 이렇게 나눴나

  • 사진을 보는 모델은 손본 이미지에서 정답률이 크게 떨어졌다는 보고가 있어요(GPT-4V: 원본 79.6% → 편집 이미지 38.4%, HallusionBench). 우리 준비물 사진으로 잰 값은 아니어서, 사진만 믿지 않게 만들었어요.
  • 그래서 안 보인 것은 "없음"이 아니라 아이가 직접 확인으로 넘겨요.
  • 통신문에서 금지·조건·수량을 찾는 일, 세기, "다 챙겼지" 판정은 규칙 코드가 하고 자동 시험 62개로 묶어 뒀어요. 사진에서는 모델이 물건과 금지물이 보이는지만 말하고, 수량이 적힌 것과 애매한 것은 아이가 직접 확인해요. 규칙도 놓칠 수 있어서, 엄마 화면에 통신문의 그 줄을 같이 보여 주고 확인받아요.
  • 같은 규칙을 MCP 도구(통신문 읽기, 챙길 것, 캘린더 글)로도 열어 AI 비서에서 부를 수 있게 했어요. 예시 서버에 Claude Code가 연결되는 것을 확인했고, 2026-11-22에는 Claude 데스크톱 앱에 연결해 도구를 불러 답하는 것까지 봤어요(아래 대화). 웹 Claude에서는 연결되지 않았고, 실제 판 서버에서 도구가 등록되는지는 아직 확인하지 못했어요.
  • 사진 확인의 정확도는 아직 재지 않았어요. 실제 사진 12장 이상으로 재고, 금지물을 놓치면 사진 확인은 빼고 "하나씩" 미션만 남길 계획이에요.

아이와 가족을 지키는 것

  • 아이는 AI와 직접 대화하지 않아요. 화면의 말은 코드가 만들어요.
  • 약과 "필요한 학생만" 준비물은 아이 화면에 나오지 않고 보호자가 정해요.
  • 사진은 저장하지 않고 확인할 때만 AI로 보내요(AI 회사의 처리 정책은 따로 있어요). 통신문은 뽑아낸 일정·준비물과 근거 줄만 남겨요. 얼굴·이름표는 찍지 않게 안내해요.
  • 로그인 없이 쓰고, 아이의 위치는 쓰지 않아요. 날씨는 보호자가 정해 둔 동네의 예보를 봐요.

실제 통신문 23건으로 재 본 것

규칙 코드만으로(모델 없이) 실제 통신문 문장을 읽혀 봤어요. 잘 읽는 것과 못 읽는 것이 갈렸고, 그래서 읽기는 AI에게, 근거 확인과 세기는 규칙에게 나눴어요.

  • "등"으로 끝나는 목록 11건 중 11건을 찾았고, 아닌 10건을 잘못 찾은 적은 없어요.
  • 가져오면 안 되는 물건은 처음 43개 중 35개(81%)를 찾았고 잘못 찾은 것이 3개였어요. 놓친 것은 "귀중품을 가지고 등교하지 않도록", "시계, 귀걸이, 목걸이는 착용하지 않습니다" 같은 표현이었고, 잘못 찾은 것은 "속옷(여벌, 세탁 불가)"의 '여벌'·'세탁'과 "이동차량 내 취식 자제"였어요. 이 표현들을 고친 뒤 같은 23건으로 다시 재니 43개 중 43개, 잘못 찾은 것 1개("… 용돈 등의 귀중품"의 '귀중품', 정답표에는 없음)예요. 고친 그 문장으로 다시 잰 값이라 새 통신문에서도 이만큼 나온다는 뜻은 아니에요.
  • "준비물:" 머리말이 있는 19건은 준비물 114개를 모두 읽었어요. 머리말 없이 표나 학년별 목록으로 적힌 4건(78개)은 하나도 못 읽었어요. 이런 글은 실제 판에서 Claude가 읽어요.
